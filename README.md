# acesup

终端 Aces Up 纸牌接龙。纯标准库,无第三方依赖。

## 玩法

- 4 个牌堆,每轮给每个堆发 1 张牌。
- 只看每堆顶牌:同花色时**小牌被大牌吃掉**(A 最大,且 A 永远不被丢)。
- A 可以移到空堆上,腾出位置继续发牌。
- 胜利条件:牌堆发完且场上只剩 4 张 A。

## 用法

```bash
python -m acesup              # 交互游玩
python -m acesup --seed 42    # 固定牌序
python -m acesup --auto       # 电脑自动打一局
```

交互命令: `d` 发牌 | `x <1-4>` 丢掉该堆顶牌 | `m <1-4>` 把该堆的 A 移到空堆 | `q` 退出。

## 设计取舍

- `--auto` 是简单贪心(有就丢、有空堆就移 A),胜率很低,仅用于回归验证——Aces Up 本来就是运气主导的游戏。
- 同一局里每张 A 最多移动一次,防止 A 在两个空堆之间来回弹导致死循环。

## 已知局限

- 无悔棋、无存档、无计分;行输入模式,每步需回车。
- 只实现标准 4 堆规则,无变体。
